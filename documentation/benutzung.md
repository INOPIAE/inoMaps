# Benutzung

## Datei
### Neue Karte einlesen

Über Datei - Neue Karte einlesen kann eine neue Karte in das Programm geladen werden. 

Es öffnet sich ein Dialog, in dem die gewünschte Datei ausgewählt werden kann. Es können die Dateiformate GeoTIFF, JPEG, PNG und BMP eingelesen werden. 

Die Karte wird in der Kartenansicht angezeigt.

Danach muss die Karte kalibriert werden. Dazu wird auf den Button "Kalibrieren" geklickt. 

Dazu müssen 4 Referenzpunkte auf der Karte gesetzt werden. jeweils in den Ecken der Karte. Die Referenzpunkte müssen in der Reihenfolge von links oben, rechts oben, rechts unten und links unten gesetzt werden.

Nach Klicken auf einen Punkt werden die Koordinaten abgefragt. Diese können entweder in Dezimalgrad oder in Grad, Minuten und Sekunden eingegeben werden.

Nach dem Setzen der 4 Referenzpunkte werden die Daten gespeichert. Dazu wird auf den Button "Kalibrieren speichern" geklickt und die Daten als JSON-Datei gespeichert. 

Mit Bild Laden kann einen neue Karte geladen werden.

### Karte Laden

Hier können bereits kalibrierte Karten geladen werden. Dazu wird die JSON-Datei ausgewählt, die beim Kalibrieren gespeichert wurde.

### Letzte Karten

Hier werden die zuletzt geladenen Karten angezeigt. Mit einem Klick auf die Karte wird diese geladen.

## Extras - Optionen

Hier können die Optionen des Programms eingestellt werden.

Es kann eingestellt werden, ob die Koordinaten in mit Punkt oder Komma als Dezimaltrennzeichen angezeigt werden.

Des Weiteren kann die Form und Größe des Markers, mit dem eine Koordinate bei der Suche angezeigt werden soll.

# Nutzung der Kartenansicht

Mit Shift + Mausrad kann in die Karte hinein- und herausgezoomt werden. Mit gedrückter linker Maustaste kann die Karte verschoben werden.

Mit Klicken auf die Karte wird die Koordinaten dieser Stelle in die Felder in der Fußzeile eingetragen.

Mit Suchen kann nach der Eingabe der Koordinaten in der Karte gesucht werden. Die Koordinaten können entweder in Dezimalgrad eingegeben werden.

Bei Ferro wird die Länge bezogen auf den Ferronischen Meridian angezeigt.

Mit Marker löschen kann der Marker, der die Koordinaten anzeigt, gelöscht werden.
