# Installation

Zur Installation zum Bereich [Releases](https://github.com/INOPIAE/inoMaps/releases) wechseln und die aktuelle Version herunterladen.

Die Datei kann direkt gestrartet werden, es ist keine Installation notwendig.

Beim ersten Start des Programmes erscheint ein Sicherheitshinweise von Windows.

![Sicherheitswarnung](images/windows_security_1.png)

Hier auf "weitere Informationen" klicken und dann auf "Trotzdem ausführen".

![Sicherheitswarnung](images/windows_security_2.png)

Bei der weitern Nutzung des Programmeswird diese Sicherheitswarnung nicht mehr angezeigt.
