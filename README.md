# inoMaps

Ein kleines Programm in dem historische Karten als Bild eingelesen werden und die geographische Koordinaten ausgelesen werden können.

Für eine genauere Ausgabe der Koordinaten, wird die  Karte kalibiert.

Das Programm stellt KEINE Karten zur Verfügung.

Zur Installation und Nutzung des Programms siehe die [Installationsanleitung](documentation/install.md).
